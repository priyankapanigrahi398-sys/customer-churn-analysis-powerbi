# Customer Churn Analysis Dashboard

An interactive Power BI dashboard designed to analyze customer churn, customer behavior, spending patterns, and key business insights through data-driven visualizations.

## 📊 Project Overview

This project focuses on understanding customer churn and identifying important factors that influence customer retention. The dashboard provides interactive insights into churn trends, customer demographics, spending behavior, and overall customer performance.

## 🚀 Key Features

- Interactive customer churn analysis dashboard
- Churn rate and customer segmentation analysis
- Customer spending and behavioral analysis
- Interactive charts and data visualizations
- Key performance indicators (KPIs)
- Business insights for customer retention strategies

## 🛠️ Technologies Used

- Power BI
- DAX
- Data Cleaning & Transformation
- Data Visualization
- Exploratory Data Analysis

## 📈 Dashboard Insights

The dashboard helps analyze:

- Customer churn trends
- Customer demographics
- Spending patterns
- Churned vs. retained customers
- Customer behavior and key churn factors
- Business performance indicators

## 🎯 Project Objective

To transform customer data into meaningful visual insights that can help businesses understand churn patterns and support data-driven customer retention decisions.
